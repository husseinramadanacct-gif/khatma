# وثيقة متطلبات المنتج والهندسة البرمجية (PRD & Architecture)
## مشروع تطبيق «خاتمة» — Khatmah

---

## 1. ملخص المنتج (Product Vision)
«خاتمة» ليس مجرد قارئ للقرآن، بل هو "رفيق الختم والمحافظة على الورد". صُمم التطبيق ليزيل عوائق المتابعة والانتظام، من خلال معرفة موضع القارئ تلقائيًا، وتقديم خيارات مرنة وغير ضاغطة للورد اليومي، وتجربة قراءة واستماع مريحة بصريًا وسمعيًا.

---

## 3. خريطة الموقع (Sitemap & Navigation)
1. **الرئيسية (`/`):**
   - بطاقة استئناف القراءة (آخر موضع).
   - بطاقة ورد اليوم مع زر البدء والاستماع.
   - بطاقة إحصائيات الختمة النشطة (النسبة، الأيام المتبقية، الصفحات المقروءة).
   - تنبيهات الورد الفائت وخيارات التعويض المرنة.
2. **المصحف الشريف (`/reader`):**
   - فهرس السور والأجزاء والأحزاب والصفحات.
   - وضع القراءة المتصلة أو وضع الصفحات.
   - شريط التحكم (نوع الخط، الحجم، السمة، ألوان التجويد).
   - قائمة إجراءات الآية (استماع، تفسير، نسخ، مشاركة، علامة).
3. **الختمات (`/khatmat`):**
   - قائمة الختمات الحالية والمكتملة.
   - معالج إنشاء ختمة جديدة (بناء الخطة، وقت الورد، وتيرة القراءة).
   - تعديل الختمة أو حذفها أو أرشفة الختمة بعد الإتمام.
4. **البحث (`/search`):**
   - محرك بحث عربي يتعامل مع التشكيل والهمزات.
   - فرز النتائج حسب السور وعرض مقتطف الآية مع التمييز.
5. **المزيد / الإعدادات (`/settings`):**
   - إعدادات القراءة والمظهر والخطوط.
   - إعدادات القارئ وسرعة الصوت.
   - العلامات المرجعية والملاحظات الشخصية.
   - إحصائيات المسيرة القرآنية.
   - مصادر البيانات والتوثيق والخصوصية.

## 5. نموذج البيانات (Data Models)
- **Khatmah:** المعرف، الاسم، نوع الورد (صفحات/أجزاء/مدة بالأيام)، الهدف، الموضع الحالي (سورة/آية/صفحة)، موعد التذكير، الحالة (نشطة/مكتملة/معلقة).
- **DailyWird:** الورد اليومي المحسوب، نطاق البداية والنهاية، حالة الإنجاز، وقت القراءة.
- **Bookmark:** معرف السورة، الآية، الصفحة، نص الآية للتوثيق، ملاحظة اختيارية، التاريخ.
- **ReadingSettings:** حجم الخط (18px - 36px)، نوع الخط (Amiri Quran / Amiri / Uthmanic)، تباعد الأسطر، تفعيل التجويد، السمة (فاتح / داكن / دافئ).

## 6. خارطة الطريق للتطوير (Development Roadmap)
1. **المرحلة الأولى:** إعداد الهوية، الأنواع، بيانات السور الـ 114 المعتمدة، وتطبيع اللغة العربية ومحركات الحسابات الرياضية.
2. **المرحلة الثانية:** طبقة الخدمات والـ Providers (النص القرآني، الصوتيات من EveryAyah، والتفسير الميسر، والتخزين).
3. **المرحلة الثالثة:** نظام الختمة والورد اليومي مع معالج الإنشاء الشامل وحفظ موضع القراءة بدقة (سورة + آية).
4. **المرحلة الرابعة:** قارئ القرآن المتقدم مع تظليل الآيات، التجويد، والتفسير الميسر، والمشاركة.
5. **المرحلة الخامسة:** المشغل الصوتي المتزامن مع كبار القراء والمشغل المصغر الدائم.
6. **المرحلة السادسة:** محرك البحث العربي الذكي مع معالجة التشكيل والهمزات، وإدارة العلامات المرجعية.
7. **المرحلة السابعة:** شاشات الإحصائيات، التنبيهات، شاشة الإتمام المباركة، فحص الجودة والأداء والتوافق.
