# تطبيق «خاتمة» — Khatmah
### *رفيقك في ختم القرآن الكريم*

«خاتمة» هو تطبيق إسلامي متخصص ومصمم بعناية فائقة لمرافقة المسلم في رحلته مع كتاب الله تعالى، عبر توفير بيئة قراءة نقية، وجدولة ذكية ومرنة للختمات والأوراد اليومية، واستماع متزامن مع كبار القراء، مع حفظ دقيق لموضع القراءة وإمكانية العمل دون اتصال.

---

## أبرز المميزات (Key Capabilities)

1. **الاستمرار الذكي (Smart Resume):** حفظ تلقائي لحظي لآخر موضع قراءة (السورة، الآية، الصفحة، الجزء) لضمان الاستئناف بنقرة واحدة فور فتح التطبيق.
2. **إدارة الختمات المتعددة:** إنشاء ومتابعة ختمات مستقلة (ختمة رمضان، ختمة شخصية، ختمة تدبر، ختمة أسبوعية).
3. **حساب الأوراد بمرونة:**
   - ورد محدد بالصفحات أو الأجزاء أو الأحزاب.
   - ورد متغير محسوب تلقائيًا بناءً على تاريخ الختم المستهدف.
   - معالجة هادئة وغير ضاغطة للأوراد الفائتة (التعويض التدريجي، تمديد الخطة، أو التخطي).
4. **مصحف إلكتروني متقدم:**
   - نص عثماني موثق معتمد برواية حفص عن عاصم.
   - خيارات التحكم بحجم الخط، والتباعد، وسمات القراءة (نهاري، ليلي، دافئ).
   - مصحف التجويد الملون مع إمكانية التبديل.
   - تنقل فوري بين السور، الأجزاء، الأحزاب، والصفحات.
5. **مشغل صوتي متزامن:**
   - استماع لأشهر القراء المعتمدين (العفاسي، الحصري، عبد الباسط، الغامدي، الشاطري).
   - تظليل مرئي للآية المتلوة بالتزامن الفعلي مع الصوت.
   - مشغل صوتي مصغر (Mini Player) يتنقل مع المستخدم بين شاشات التطبيق.
6. **محرك بحث عربي ذكي:**
   - تطبيع نصوص البحث (معالجة الهمزات، التشكيل، الألف المقصورة والياء، وعلامات الوقف).
   - عرض مقتطفات الآيات مع تمييز الكلمات والانتقال الفوري للآية في المصحف.
7. **تفسير ميسر ومشاركة:**
   - التفسير الميسر المعتمد لكل آية بضغطة زر.
   - نسخ الآيات مع تخريج السورة والآية، ومشاركة بطاقات الآيات.
8. **العلامات المرجعية والملاحظات:**
   - حفظ مواضع الآيات المفضلة مع إمكانية تدوين ملاحظات شخصية وتدبرية.
9. **الخصوصية والعمل دون اتصال (Offline & Privacy):**
   - حفظ محلي فوري لجميع الختمات والتقدم دون الحاجة لأي تسجيل دخول.
   - تخزين ذكي للسور والصفحات المقروءة.

## التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 19 + TypeScript + Vite.
- **Styling & Theme:** Tailwind CSS v4 + Framer Motion (Transitions).
- **Typography:** Amiri Quran, Amiri, Cairo, Plus Jakarta Sans.
- **Icons:** Lucide React.
- **Data & Audio Providers:** Al-Quran Cloud API, EveryAyah CDN, King Fahd Complex Data.
- **Storage:** LocalStorage & IndexedDB Caching Layer.

## التشغيل المحلي (Getting Started)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```

يعمل التطبيق على المنفذ `3000` بواجهة عربية كاملة `dir="rtl"`.
